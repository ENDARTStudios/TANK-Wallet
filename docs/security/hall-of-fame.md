# Security Hall of Fame

> Tank Wallet recognizes security researchers who help us protect our users.
> Listed below are researchers who reported valid vulnerabilities through
> our bug bounty program or private disclosure.
>
> We thank each one of them for making Tank Wallet safer.

---

## How to be listed

1. Report a valid vulnerability via `security@tankwallet.dev` (PGP) or
   via our [Immunefi bug bounty program](https://immunefi.com) (when live).
2. The report must be confirmed as a real vulnerability by our security team.
3. After the fix is deployed and the 90-day grace period passes, the
   researcher is added to this page (unless they prefer to remain anonymous).
