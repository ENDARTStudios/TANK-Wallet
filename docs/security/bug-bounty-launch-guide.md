# Bug Bounty Launch Guide — For the Operador

> Passo a passo simples para lançar o programa de bug bounty no Immunefi.
> O Doer preparou tudo — você só precisa criar a conta e publicar.

---

## Pré-requisitos

1. Conta no GitHub (já existe).
2. Conta no [Immunefi](https://immunefi.com/) (criar — é grátis).
3. Arquivo `BUG-BOUNTY.md` na raiz do repositório (já existe).

---

## Passo a passo

### 1. Criar conta no Immunefi
- Acesse https://immunefi.com/
- Clique em "Sign Up"
- Use o email `endart.studios@gmail.com`
- Complete o perfil do projeto

### 2. Criar o programa de bug bounty
- Clique em "Start a Bug Bounty"
- Nome do projeto: **Tank Wallet**
- Categoria: **DeFi / Wallet**
- Descrição: copie do `README.md` (primeira seção)

### 3. Configurar escopo
- Copie a tabela de "In scope" do `BUG-BOUNTY.md`
- Adicione a URL do repositório GitHub
- Adicione a URL do site (quando estiver no ar)

### 4. Configurar recompensas
- Copie a tabela de "Reward Tiers" do `BUG-BOUNTY.md`
- Critical: $1,000 – $5,000
- High: $250 – $1,000
- Medium: $100 – $250
- Low: $50 – $100

### 5. Configurar regras
- Copie as regras do `BUG-BOUNTY.md`
- Destaque: "No public disclosure before fix + 90 days"

### 6. Publicar
- Revise tudo
- Clique em "Publish"
- O programa fica visível para researchers em 24-48h

### 7. Adicionar badge ao README
- Após publicar, o Immunefi fornece um badge URL
- O Doer adicionará ao README.md quando você fornecer o link

---

## Como saber que deu certo

- O programa aparece em https://immunefi.com/bounty/tankwallet
- Researchers começam a enviar reports
- Você recebe notificações por email

---

Responda "feito o item SEC-004" para o Doer atualizar o status no `PLANO_MESTRE.md`.
